# styles.refero.design, Real Design System Summaries

## What it is
A collection of 2,000+ extracted DESIGN.md-style summaries of real shipped products' design systems (color palette, type scale, spacing, component conventions), each written in an evocative, atmospheric per-product voice (e.g., Linear described as a "midnight precision instrument").

## What to extract
- Concrete, real-world reference points for what a *specific* product's design language looks like when you need to match or riff on it (e.g. "make this feel like Linear" or "make this feel like Stripe's docs").
- The summary format itself is a useful model: palette + type scale + spacing + component notes, written tersely enough for an AI agent to act on directly.
- This is the only source in this skill built specifically for AI coding agents rather than human browsing, treat it as the first place to check when a request references an existing product's look and feel.

## When to use this
Reach for this when the user names a real product as a reference point, or asks for a "design system" rather than a one-off page. Also useful as a structural template for writing up this project's own design conventions if that's ever needed.

## Caveats
None known, freely accessible at last check. Content is a third-party's interpretation of each product's system, not the product's own official design documentation; treat as a strong starting point, not ground truth.
